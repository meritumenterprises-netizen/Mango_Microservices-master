# Xango.React.Application

React migration of `Xango.Angular.Application`.

## Scripts

```powershell
npm install
npm run dev
npm run build
```

The app uses the same backend service URLs as the Angular application. Override them with Vite environment variables such as `VITE_AUTH_API`, `VITE_PRODUCT_API`, `VITE_COUPON_API`, `VITE_SHOPPINGCART_API`, and `VITE_ORDER_API`.
